# Задание:
<ul>
  <li>Инициализировать проект ( npm init ), установить Express</li>
  <li>Создать сервер, который отдаёт статические файлы (HTML, CSS, JS).</li>
  <li>Реализовать несколько маршрутов: / (главная), /about (о себе), /api/status (JSON ответ).</li>
  <li>Научиться работать с параметрами запроса и query-параметрами.</li>
  <li>Добавить манифест (manifest.json) с иконками и подключить его в HTML.</li>
  <li>Реализовать service worker: кешировать статику и обеспечить работу приложения
офлайн, зарегистрировать его на странице.</li>
</ul>

## Вариант 6. Тема «Погода по городу» (mock API).
Маршруты: GET /, GET /about, GET /api/weather/:city.
Логика: фиктивные данные для 5 городов (хардкод).
Query ?units=metric переключает единицы (C/F).
Ответ: { city: "Moscow", temp: 23, units: "C", condition: "clear" }.
Ошибки: город не найден → 404 + { error: "City not found" }.
